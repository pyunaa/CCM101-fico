# Microsoft Azure

Microsoft Azure is a public cloud computing platform developed by Microsoft. Azure provides cloud services for computing, storage, networking, databases, security, artificial intelligence, analytics, containers, application development, and enterprise workloads. Azure is particularly useful for organizations that already use Microsoft technologies such as Windows Server, Microsoft 365, Active Directory, SQL Server, and other Microsoft enterprise products.

## Global Infrastructure

Microsoft Azure operates a global infrastructure consisting of geographic regions and datacenter infrastructure. Azure provides cloud locations around the world that allow organizations to deploy applications closer to their users.

Azure's global infrastructure supports:

- High availability
- Disaster recovery
- Geographic redundancy
- Data residency
- Low-latency application deployment
- Enterprise workloads

---

## Cloud Management Console

The Microsoft Azure Portal is a web-based management interface for Azure resources.

The portal allows users to:

- Create virtual machines.
- Configure storage.
- Create databases.
- Manage networks.
- Configure identities.
- Monitor applications.
- Manage security.
- Review costs.

## Four Core Azure Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides scalable virtual machines running Windows or Linux operating systems.

Virtual machines can be used for:

- Web servers
- Application servers
- Development environments
- Enterprise applications
- Linux workloads
- Windows Server workloads

---

### 2. Azure Blob Storage

Azure Blob Storage is Microsoft's object storage service. Blob Storage is commonly used for scalable cloud data storage.

It can store large amounts of unstructured data such as:

- Images
- Videos
- Documents
- Backups
- Logs
- Application data

---

### 3. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud identity and access management service.

It helps organizations manage:

- Users
- Groups
- Applications
- Authentication
- Access permissions
- Identity policies

It is especially useful for organizations already using Microsoft identity technologies.

---

### 4. Azure Virtual Network

Azure Virtual Network provides networking capabilities for Azure resources.

It allows organizations to configure:

- Virtual networks
- Subnets
- IP addresses
- Routing
- Network security
- Connections to on-premises networks

---

## Three Advantages of Azure

### 1. Microsoft Integration

Azure integrates strongly with Microsoft technologies such as Windows Server, Microsoft 365, Microsoft Entra ID, and SQL Server.

### 2. Enterprise Support

Azure provides services designed for enterprise organizations, including identity, security, compliance, networking, and hybrid-cloud capabilities.

### 3. Hybrid Cloud Capabilities

Azure supports organizations that need to connect existing on-premises infrastructure with cloud services.
