# Client Recommendations

## CloudNova Technologies – Cloud Platform Recommendation Challenge

The following recommendations are based on the technical and business requirements provided by each client.

---

# Client A – Startup Company

## Recommended Platform: AWS

AWS is recommended for the startup because it provides a broad range of services that can support a mobile application from development to production. AWS also provides scalable services that allow the startup to begin with relatively small infrastructure and increase resources as the application gains users. This is important because the company has a limited budget but expects rapid growth. AWS also provides services suitable for mobile backends, databases, storage, authentication, and application hosting.

### Possible Services

1. Amazon EC2
2. Amazon S3
3. Amazon RDS
4. Amazon Cognito

---

# Client B – University

## Recommended Platform: Microsoft Azure

Microsoft Azure is the recommended platform because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's identity, server, productivity, and enterprise technologies. This can make migration easier because the university can continue using familiar Microsoft technologies while extending its infrastructure into the cloud. Azure also provides hybrid-cloud capabilities that can help connect existing on-premises systems with cloud resources.

### Possible Services

1. Azure Virtual Machines
2. Microsoft Entra ID
3. Azure SQL Database
4. Azure Virtual Network

---

# Client C – AI Research Company

## Recommended Platform: Google Cloud

Google Cloud is recommended for the AI research company because it has strong capabilities for artificial intelligence, machine learning, data processing, and high-performance workloads. Google Cloud provides specialized infrastructure and services that can support AI and ML development. The company can also use Google Cloud's data analytics and machine learning services to process large datasets and develop AI models. GPU and other accelerator-based infrastructure can be selected for computationally intensive workloads.

### Possible Services

1. Compute Engine
2. Vertex AI
3. Cloud Storage
4. Google Kubernetes Engine

---

# Client D – Global E-Commerce Company

## Recommended Platform: AWS

AWS is recommended for the global e-commerce company because it provides a broad set of services for highly available and scalable applications. The company can deploy workloads across multiple Availability Zones and Regions to improve availability and resilience. AWS also provides load balancing, automatic scaling, databases, storage, and monitoring services that are useful for global online shopping systems. These capabilities allow the infrastructure to respond to changes in customer traffic.

### Possible Services

1. Amazon EC2
2. Elastic Load Balancing
3. Amazon RDS
4. Amazon S3
5. Amazon CloudFront
6. Amazon EC2 Auto Scaling
