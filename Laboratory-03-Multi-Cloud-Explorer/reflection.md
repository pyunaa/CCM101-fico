# REFLECTION

Mission 3 helped me understand the differences between AWS, Azure, and Google Cloud. I was most impressed by Google Cloud because of its strong AI, Machine Learning, and Kubernetes services.

I learned that all three cloud providers offer similar services, but each has different strengths. Azure is useful for organizations using Microsoft technologies, AWS offers many services and scalability, while Google Cloud is strong in AI and data analytics.

This mission taught me that cloud providers should be selected based on the client's budget, requirements, existing technology, and future goals. I also improved my Linux skills, cloud knowledge, Markdown documentation, and GitHub portfolio.
