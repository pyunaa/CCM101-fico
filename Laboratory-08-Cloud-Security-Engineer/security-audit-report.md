# Security Audit Report

## Mission 8: The Cloud Security Engineer

### 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users, applications, and services only the permissions they need to perform their assigned tasks. It is important in cloud environments because limiting unnecessary access reduces the risk of accidental changes, unauthorized activities, and data breaches.

### 2. Attack Surface

An attack surface is the collection of possible entry points that an attacker could use to access or compromise a virtual machine. These entry points may include open network ports, running services, exposed applications, and accounts with weak credentials. Reducing unnecessary services and restricting access helps minimize the attack surface.

### 3. Default Deny Policy

A Default Deny policy blocks incoming network traffic unless a firewall rule explicitly permits it. This is safer than blocking individual attackers because unknown or newly emerging threats are also restricted unless they match an authorized rule. Only the network connections required for legitimate operations should be allowed.
