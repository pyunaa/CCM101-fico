# Mission 9 Reflection

Throughout this laboratory activity, I learned how automation can improve the efficiency and reliability of cloud operations. Managing hundreds or thousands of cloud servers manually would require a significant amount of time and could lead to human errors. Automation is critical because it allows administrators to perform repetitive tasks consistently, such as creating backups, updating systems, and monitoring resources. Using Bash scripts and Cron jobs can help reduce manual work and prevent important tasks from being forgotten.

However, automation also has potential dangers. A small mistake in a script can cause serious problems if it is executed across many servers. For example, a destructive command or incorrect directory path could delete important files on 1,000 servers. This is why scripts should be tested in a safe environment before deployment. Administrators should also use appropriate permissions, review commands carefully, maintain backups, and monitor automated tasks.

Writing a Bash script was different from creating a Docker Compose YAML file in Laboratory 6. Bash scripting focuses on executing commands sequentially to perform tasks, such as creating directories and compressing files. Docker Compose uses YAML to describe and configure application services, networks, and storage. Both tools support automation, but they solve different problems in cloud computing.

Reviewing my GitHub portfolio from Laboratory 1 to Laboratory 9 helped me understand how the different areas of cloud computing work together. I progressed from learning basic cloud concepts to exploring infrastructure, cloud-native applications, data storage, deployment, operations, security, and automation. I now understand that cloud computing involves more than simply running applications online; it also requires reliable management, security, monitoring, and efficient resource utilization.

The role I enjoyed most was the Cloud Automation Engineer because I learned how to turn repeated manual commands into a reusable script and schedule it to run automatically. This activity helped me appreciate how automation can make IT operations more efficient and reliable. Overall, this laboratory improved my confidence in using Linux commands, writing scripts, and documenting technical work. I will apply these skills in future cloud computing projects.
