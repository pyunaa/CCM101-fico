## Reflection Questions

### 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are the most important cloud infrastructure component because they provide the processing power needed to run applications and services. Without compute resources, other components such as storage and networking cannot effectively support running applications.

### 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable, secure, and flexible operating system for servers and cloud environments. It also provides powerful command-line tools that allow cloud engineers to manage servers, networking, storage, applications, and other resources efficiently.

### 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the system requirements, configurations, commands, and procedures needed for deployment. It helps prevent mistakes, makes troubleshooting easier, and allows other team members to understand and maintain the infrastructure.

### 4. What new skills did you learn during this laboratory activity?

I learned how to use basic Linux commands to identify system information such as the operating system, CPU, memory, storage, hostname, and IP address. I also learned how to document my work using Markdown and GitHub more professional.

### 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I was able to add a documented laboratory activity that demonstrates my Linux, cloud computing, and technical documentation skills. It also shows that I can organize information using Markdown and use GitHub to present my technical work professionally.
