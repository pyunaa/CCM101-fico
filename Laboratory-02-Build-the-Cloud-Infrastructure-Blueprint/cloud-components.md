# Cloud Infrastructure Components

## 1. Compute Resources

### Purpose

The CPU processes commands, applications, and other tasks performed by the system.

### Importance in Cloud Computing

Compute resources provide the processing power needed to run applications, virtual machines, containers, and cloud services.

### KillerCoda Environment

KillerCoda provides a virtual CPU with 1 core. This allows Ubuntu to execute commands and run the activities in the lab.

## 2. Storage Resources

### Purpose

Storage is used to save the operating system, applications, configuration files, and user data.

### Importance in Cloud Computing

Cloud systems need storage to keep data available even when applications or virtual machines are restarted or changed.

### KillerCoda Environment

The Linux environment has a 19 GB virtual disk, with about 5.4 GB used and 13 GB available.

## 3. Networking Resources 

### Purpose

Networking allows the system to communicate with other systems, containers, and services.

### Importance in Cloud Computing

Networking connects cloud servers and allows users and applications to communicate with cloud resources over a network.

### KillerCoda Environment

KillerCoda assigns IP addresses to the Linux environment. These addresses allow the virtual environment and its services to communicate within its network.

## 4. Operating System 

### Purpose

The operating system manages the CPU, memory, storage, networking, and applications.

### Importance in Cloud Computing

The OS provides the platform where cloud applications and services can run and be managed.

### KillerCoda Environment

KillerCoda uses Ubuntu 24.04.4 LTS with kernel 6.8.0-136-generic. It provides the command-line environment used to perform the laboratory activities.
